## Journey model (all clinical roles)

Atlas moves enrollees through **Regulation → Readiness → Renewal**. Gates, regression, and the strip map are documented in [journey-phases.md](./journey-phases.md).

## Important access rule

Signing in determines what data you can see. The on-screen **role switcher** only changes menus and layout. It does **not** expand your data access. Information Technology (IT) enforces access with Row-Level Security (RLS) on your signed-in identity.
